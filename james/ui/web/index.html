Duplex mode

Duplex sessions are wake-gated: JAMES listens for the wake word, opens a live session, and closes it after the idle timeout. Speak over an answer to interrupt it.

Tools

Tools outside the allowlist are denied. Dangerous tools require your confirmation before they run.

Integrations

One-click MCP servers — enable one and its tools appear in the registry immediately. Servers need npx (Node.js) and the mcp extra: pip install "james-assistant[mcp]".

Cloud plugin marketplace

JAMES syncs the plugin catalog from a GitHub-hosted registry. Remote plugins still require a valid signature before they can be installed.

Messaging gateway

Bridge Telegram, WhatsApp, Discord and Slack to JAMES. Configure tokens in .env (TELEGRAM_BOT_TOKEN, DISCORD_BOT_TOKEN, SLACK_APP_TOKEN/SLACK_BOT_TOKEN, TWILIO_*) and set GATEWAY_ENABLED=true.

Recipes

Named multi-step automations. Compose one in plain language ("every morning summarize my emails and notify me") and JAMES turns it into tool steps.
